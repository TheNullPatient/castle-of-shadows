# 🏰 Castle of Shadows

Roguelike с процедурной генерацией подземелий, полем зрения, инвентарём и
10 уровнями. Рендер — ASCII в SDL-окне через `python-tcod`, шрифт —
`DejaVuSansMono.ttf` (адаптивный тайлсет под размер окна и дробное
масштабирование).

## Запуск

```bash
python3 -m pip install -r requirements.txt
python3 main.py
```

`python3 castle.py` — совместимая обёртка над `main.py`.

Окно можно свободно растягивать: игра пересоберёт шрифт под новый размер и
заполнит высоту, оставив чёрные поля только по бокам (пропорции не искажаются).

## Управление

| Клавиши | Действие |
|---------|----------|
| `WASD` / стрелки / `hjkl` | движение |
| движение в врага | атака |
| `.` / `Space` | подождать |
| `>` / `Enter` на лестнице | спуск |
| `i`, затем `a-z` | инвентарь / использовать или экипировать |
| `Del`, затем `a-z` в инвентаре | выбросить предмет в мусорку |
| `x` на мусорке `%` | посмотреть содержимое мусорки |
| `Esc` | закрыть инвентарь или мусорку |
| `PgUp` / `PgDn`, `-` / `=` | прокрутка лога |
| `?` / `F1` | помощь |
| `Q` | выход |
| `R` на экране смерти | начать заново |

## Предметы

- Рюкзак вмещает 26 предметов (`a-z`).
- Зелья складываются в стопку до 8 штук, свитки — до 4. Оружие и броня
  не стакаются.
- У оружия и брони есть прочность: оружие изнашивается при атаке игрока,
  броня — когда враги бьют игрока. Сломанный предмет исчезает из рюкзака
  и с экипировки; прочность видна в инвентаре.
- В углу одной из комнат стоит мусорка `%` вместимостью 8 стопок. Встаньте
  на неё, откройте инвентарь, нажмите `Del` и выберите предмет. Клавиша `x`
  на мусорке открывает её содержимое — предметы можно забрать обратно.

## Структура

- `main.py` — окно, тайлсет, ввод.
- `game.py` — состояние игры, бой, FOV, ходы, статистика.
- `dungeon.py` — генерация комнат и коридоров.
- `entities.py` — сущности, враги, лут.
- `inventory.py` — рюкзак, экипировка, свитки.
- `ui.py` — отрисовка карты и панелей.
- `constants.py` — размеры, цвета, константы.
- `assets/` — шрифт и запасной PNG-тайлсет.

## Идеи для развития

Сохранение, миникарта, магазин за золото, ловушки и секретные двери,
статус-эффекты, энергетическая система (speed), биомы по глубине, звук
и анимации.
